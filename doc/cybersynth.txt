INTRODUCTION                                            *cybersynth-introduction*

cybersynth.nvim is a plugin-agnostic Neovim colorscheme inspired by synthwave,
outrun, and retrowave aesthetics. It styles Neovim's core highlight groups so
that well-behaved plugins inherit correct colors automatically.

Key features~
  - Plugin-agnostic: styles hub groups, not plugin names
  - Dark and light variants with matching hue families
  - WCAG AAA contrast on dark, AA on light
  - Zero required configuration: `:colorscheme cybersynth` and done
  - Lua setup() API for customization
  - Neovim >= 0.10 required

INSTALLATION                                            *cybersynth-installation*

See the README on GitHub for full installation instructions for all package
managers.

lazy.nvim~                                                       *cybersynth-lazy*
>lua
  {
    "Web-Dev-Codi/cybersynth.nvim",
    lazy = false,
    priority = 1000,
    config = function()
      require("cybersynth").setup({})
      vim.cmd.colorscheme("cybersynth")
    end,
  }
<

vim-plug~                                                     *cybersynth-vim-plug*
>vim
  Plug 'Web-Dev-Codi/cybersynth.nvim'
  lua require('cybersynth').setup({})
  colorscheme cybersynth
<

CONFIGURATION                                          *cybersynth-configuration*

Call |require("cybersynth").setup()| before |:colorscheme cybersynth|.

Default configuration:~
>lua
  require("cybersynth").setup({
    variant = "auto",     -- "dark" | "light" | "auto" (follows vim.o.background)
    transparent = false,  -- make backgrounds transparent (NONE)

    italic = {
      comments = true,
      keywords = false,
      functions = false,
      variables = false,
      strings = false,
    },

    bold = {
      functions = false,
    },

    overrides = {},       -- per-group overrides applied after all highlights
  })
<

Options~

  variant ~
    Type: string, default: "auto"
    Which palette variant to use. "auto" follows |vim.o.background|.

  transparent ~
    Type: boolean, default: false
    When true, sets `bg = "NONE"` on Normal, NormalFloat, SignColumn,
    StatusLine, TabLine, and related groups.

  italic ~
    Type: table
    Controls which semantic groups render in italic. Keys: comments,
    keywords, functions, variables, strings.

  bold ~
    Type: table
    Controls bold rendering. Key: functions.

  overrides ~
    Type: table
    Table of per-group highlight overrides applied after all theme groups
    are loaded. Format:
>lua
      overrides = {
        Normal = { bg = "#000000" },
        ["@keyword"] = { fg = "#ff0000" },
      },
<

HIGHLIGHT GROUPS                                    *cybersynth-highlight-groups*

cybersynth defines the following categories of highlight groups:

  Editor UI~
    Normal, NormalNC, NormalFloat, FloatBorder, FloatTitle, WinSeparator,
    CursorLine, CursorLineNr, LineNr, SignColumn, FoldColumn, Folded,
    StatusLine, StatusLineNC, WinBar, WinBarNC, TabLine, TabLineSel,
    TabLineFill, Pmenu, PmenuSel, PmenuSbar, PmenuThumb, PmenuMatch (0.11+),
    Visual, Search, IncSearch, CurSearch, MatchParen, NonText, EndOfBuffer,
    Whitespace, ColorColumn, DiffAdd, DiffChange, DiffDelete, DiffText,
    DiagnosticError, DiagnosticWarn, DiagnosticInfo, DiagnosticHint,
    DiagnosticOk, and all severity x renderer variants.

  Standard syntax~
    Comment, Constant, String, Number, Boolean, Identifier, Function,
    Statement, Conditional, Repeat, Operator, Keyword, PreProc, Type,
    StorageClass, Structure, Special, Tag, Delimiter, Error, Todo, etc.

  Treesitter captures~
    @variable, @function, @keyword, @type, @string, @comment, @number,
    @boolean, @operator, @punctuation, @constructor, @attribute, @property,
    @module, @label, @tag, @markup.*, @diff.*, and deprecated @text.* links.

  LSP semantic tokens~
    @lsp.type.* (links to corresponding @-groups), @lsp.mod.*,
    @lsp.typemod.*.*, LspReferenceText, LspReferenceRead, LspReferenceWrite,
    LspSignatureActiveParameter, LspCodeLens, LspInlayHint.

  Diagnostic groups~
    DiagnosticError/Warn/Info/Hint/Ok, DiagnosticVirtualText*,
    DiagnosticVirtualLines* (0.11+), DiagnosticUnderline*,
    DiagnosticFloating*, DiagnosticSign*, DiagnosticDeprecated,
    DiagnosticUnnecessary.

OVERRIDES                                                *cybersynth-overrides*

Get the active palette:~
>lua
  local colors = require("cybersynth").get_colors()
  local palette = require("cybersynth").get_palette()
<

Override a specific highlight after loading:~
>lua
  vim.api.nvim_set_hl(0, "Comment", { fg = "#ff0000" })
<

Use the |on_highlights| equivalent via config.overrides:~
>lua
  require("cybersynth").setup({
    overrides = {
      Comment = { fg = "#ff0000", italic = true },
    },
  })
  vim.cmd.colorscheme("cybersynth")
<
